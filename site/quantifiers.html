Quantifiers

All. Some. And why order matters.

Connectives join whole statements. Quantifiers reach inside them and say how many objects make a statement true: all of them, or at least one. With them you can write down almost any claim in mathematics.

∀

for all

∀x P(x): every object makes P true. One counterexample makes it false.

∃

there exists

∃x P(x): at least one object makes P true. One example makes it true.

Reading nested quantifiers

∀x ∃y versus ∃y ∀x

Read left to right, as a game. In ∀x ∃y, your opponent picks x first, then you get to choose y knowing x. Each x can get its own y.

In ∃y ∀x, you must commit to one y first, and it has to work for every x. That's much harder, which is why the second statement implies the first but not the other way round.

Numbers this time
∀x ∈ ℤ ∃y ∈ ℤ (y > x)
Every integer has a bigger one. Take y = x + 1.true
∃y ∈ ℤ ∀x ∈ ℤ (y > x)
Some integer beats them all, itself included. Impossible.false
Translating

Common patterns

Notice which pattern uses → and which uses ∧. Getting this wrong is one of the most common translation mistakes.

All A's are B's∀x (A(x) → B(x))

“Every prime greater than 2 is odd.” Using ∧ here would claim everything is an A.

Some A is a B∃x (A(x) ∧ B(x))

“Some prime is even.” Using → here would be true almost by accident, whenever anything fails to be an A.

No A is a B∀x (A(x) → ¬B(x))

Equivalently ¬∃x (A(x) ∧ B(x)).

Universe of discourse

Quantifiers range over some agreed collection: integers, reals, people. ∃x (x² = 2) is true in ℝ and false in ℚ. When it matters, write ∃x ∈ ℝ.
