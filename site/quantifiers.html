Quantificational Logic

All. Some. Exactly one.

∀ and ∃ let you talk about every object at once, or promise that a single one exists. They also bring a new trap: changing their order can change what a statement says.

See why order mattersNegate anything
∀x ∃y

Everyone loves someone.

∃y ∀x

Someone is loved by everyone.

Key ideas

Universal

∀x P(x): P is true of everything.

Read it as “for all x”. One counterexample makes it false.

∀
Existential

∃x P(x): at least one thing makes P true.

Read it as “there exists an x”. One example makes it true.

∃
Negation

“Not all” means “some… not”.

A negation moves past a quantifier by flipping it: ∀ becomes ∃ and ∃ becomes ∀.

¬∀x P ≡ ∃x ¬P
Order

∀x∃y is not ∃y∀x.

In the first, each x may get a different y. In the second, a single y has to work for every x.

∀∃ ≠ ∃∀
Uniqueness

∃!x P(x): exactly one.

This is shorthand. It means something has property P, and anything else with property P is that same thing.

∃!
Power sets

𝒫(A) is the set of all subsets of A.

If A has n elements, 𝒫(A) has 2ⁿ. These sets are the key to Cantor's theorem in Chapter 7.

|𝒫(A)| = 2n

§2.2

The negation machine

To prove something is false you often need its negation in a positive form. Push the ¬ inward one step at a time. It flips each quantifier it passes, and De Morgan's laws handle ∧ and ∨.

The result is a statement you can actually work with in a proof.

Quantifiers meet sets

Most definitions in the rest of the book are written with these four patterns.

Bounded quantifiers
∀x ∈ A P(x)

is short for ∀x(x ∈ A → P(x)), and ∃x ∈ A P(x) for ∃x(x ∈ A ∧ P(x)). Note the → in one and the ∧ in the other.

Subsets
A ⊆ B

means ∀x(x ∈ A → x ∈ B). Two sets are equal when each is a subset of the other, so they have exactly the same elements.

Vacuous truth

Every element of ∅ is purple.

∀x ∈ ∅ P(x) is true whatever P says, because there's nothing in ∅ to be a counterexample. So ∅ ⊆ A for every set A.

Families of sets

Sets whose elements are sets.

⋃F is everything in at least one set of F. ⋂F is everything in all of them. For F = {{1,2,3}, {2,3,4}, {3,4,5}}: ⋃F = {1,…,5} and ⋂F = {3}.

Indexed families

Name the sets with an index.

⋃i∈I Ai and ⋂i∈I Ai are the same idea with a label for each set. For example, Aᵢ could be the multiples of i.

§2.3

The power set doubles every time

𝒫(A) contains every subset of A, including ∅ and A itself. Each new element can be either in or out of a subset, so adding one element doubles the count.

Remember this set. In Chapter 7 it shows that some infinite sets are bigger than others.

𝒫({1, …, n})
