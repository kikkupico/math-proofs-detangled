√2 Is Irrational

A contradiction with a lemma inside.

Theorem

There are no integers p and q with q ≠ 0 such that p/q = √2.

Tools

Quantifier lawsConditionals

Techniques

ContradictionContrapositiveWitnesses
The lemma we need

If n² is even, then n is even.

Proved by contrapositive on the Contrapositive page: if n is odd, n² is odd.

A fact about fractions

Every fraction can be written in lowest terms: numerator and denominator with no common factor bigger than 1.

The proof, line by line

Both even? Impossible.

“Irrational” means “not a fraction”: a negative goal. So assume it is a fraction and chase the consequences.

Negative goal → contradiction

Suppose √2 is a fraction

The goal is ¬∃p, q (…). Assume the opposite: some fraction equals √2. It's an ∃ given, so name it, and take it in lowest terms.

Algebra

Clear the square root

Square both sides and multiply by q². Now we have an equation between integers, which is much easier to reason about.

Lemma + ∃ given

p is even

p² = 2q² is even, so by the lemma p is even. Unpack: p = 2k for some integer k.

Same again

q is even too

Substitute: 4k² = 2q², so q² = 2k². The same reasoning, now for q, says q is even.

Contradiction

Lowest terms, but both even

If p and q are both even, 2 is a common factor, so p/q wasn't in lowest terms. That contradicts how we chose them.

Proof
Suppose, for contradiction, that √2 = p/q for some integers p, q with q ≠ 0. We may assume the fraction is in lowest terms. Squaring gives 2 = p²/q², so p² = 2q². So p² is even, and therefore p is even, say p = 2k. Then 4k² = 2q², so q² = 2k². So q² is even, and therefore q is even. Then 2 divides both p and q, contradicting that p/q is in lowest terms. So √2 is irrational. ∎

Show the Lean code
import Mathlib

/-! √2 is irrational, in integer form: if p/q is in lowest terms
(gcd p q = 1), then p² ≠ 2q². Mathlib also has this as `irrational_sqrt_two`. -/

example (p q : ℕ) (hpq : Nat.Coprime p q) : p ^ 2 ≠ 2 * q ^ 2 := by
  intro h                                 -- Suppose p² = 2q².
  -- p² is even, so p is even: p = 2k.
  have hp : 2 ∣ p := Nat.Prime.dvd_of_dvd_pow Nat.prime_two ⟨q ^ 2, h⟩
  obtain ⟨k, rfl⟩ := hp
  -- Then 4k² = 2q², so q² = 2k², and q is even too.
  have hq2 : q ^ 2 = 2 * k ^ 2 := by
    ring_nf at h ⊢
    linarith
  have hq : 2 ∣ q := Nat.Prime.dvd_of_dvd_pow Nat.prime_two ⟨k ^ 2, hq2⟩
  -- 2 divides both, so it divides gcd(2k, q) = 1. Contradiction.
  have h2 : 2 ∣ Nat.gcd (2 * k) q := Nat.dvd_gcd (dvd_mul_right 2 k) hq
  rw [Nat.Coprime.gcd_eq_one hpq] at h2
  omega
