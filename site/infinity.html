Infinite Sets

Some infinities are bigger.

Counting a set means matching its elements with 1, 2, 3, …. Take that definition seriously and you can compare the sizes of infinite sets, and find that they don't all match.

Key ideas

Equinumerous

A ∼ B means there's a one-to-one, onto f : A → B.

Counting a finite set is exactly this kind of matching with {1, …, n}. Chapter 5 supplies the tools.

Part = whole?

ℤ⁺ ∼ ℤ.

The positive integers match up with all the integers, even though ℤ contains ℤ⁺ and more. This can only happen with infinite sets.

ℤ⁺ × ℤ⁺ ∼ ℤ⁺.

Count the pairs along diagonals and every pair gets a number. The same idea shows ℚ is denumerable.

Finite, or matched with ℤ⁺.

Countable sets can be listed. A countable union of countable sets is still countable.

Cantor's theorem

𝒫(ℤ⁺) is uncountable.

Any list of subsets of ℤ⁺ misses one. The missing set is built by going down the diagonal and flipping every answer.

𝒫(ℤ⁺)
Cantor–Schröder–Bernstein

One-to-one both ways implies the same size.

If A ≼ B and B ≼ A then A ∼ B. One consequence: ℝ ∼ 𝒫(ℤ⁺).

A ≼ B ≼ A
§7.1

The part can be as big as the whole

The book's matching between ℤ⁺ and ℤ: send even n to n/2 and odd n to (1 − n)/2. The positives land on 1, 2, 3, … and the odds land on 0, −1, −2, …. Nothing is hit twice, and nothing is missed.

To show two sets are the same size you need only one such function. The many functions that fail don't matter.

f : ℤ⁺ → ℤ

Every integer m is hit exactly once: by 2m if m > 0, and by 1 − 2m if m ≤ 0.

Counting a grid, one diagonal at a time

The pairs of positive integers fill an infinite grid, which looks like far more than one infinite line. But run along the diagonals in turn and every pair gets a number. The book's formula is

f(i, j) = (i + j − 2)(i + j − 1)/2 + i

Drag the slider to count. Every cell is reached eventually.

ℤ⁺ × ℤ⁺ → ℤ⁺

Try it · §7.2

Try to list every subset of ℤ⁺

Each row is one subset in your list. A filled square in column n means n is in that set. Cantor's set D = {n ∈ ℤ⁺ | n ∉ f(n)} flips the diagonal, so it disagrees with row n about n, for every n. Add D to the list and a new D appears.

The rest of the landscape

Once you have one countable set and one uncountable one, the other results follow in a few lines each.

Theorem 7.1.6

ℚ is denumerable.

Rationals are fractions, so they are essentially pairs of integers. Since ℤ⁺ × ℤ⁺ ∼ ℤ⁺, the rationals can be listed too.

Theorems 7.2.1–7.2.4

Countable stays countable.

If A and B are countable, so are A × B and A ∪ B. A countable union of countable sets is countable. So is the set of all finite sequences from a countable set.

Theorem 7.2.6

ℝ is uncountable.

Decimal expansions give a one-to-one map from 𝒫(ℤ⁺) into ℝ. A consequence: since ℚ is countable, the irrationals ℝ ∖ ℚ must be uncountable.

Definition 7.3.1

A ≼ B: B dominates A.

There's a one-to-one function from A to B. ≼ is reflexive and transitive but not antisymmetric, because ℤ⁺ ≼ ℚ and ℚ ≼ ℤ⁺ while ℤ⁺ ≠ ℚ. So it isn't a partial order.

Theorem 7.3.2 · Cantor–Schröder–Bernstein

If A ≼ B and B ≼ A, then A ∼ B.

Building a bijection directly is often hard. This theorem lets you instead find two one-to-one functions, one in each direction, which is usually much easier. The book uses it to show ℝ ∼ 𝒫(ℤ⁺) (Theorem 7.3.3). The proof combines functions (Ch. 5), unions of families (Ch. 2) and recursion (Ch. 6), so it makes a good final exam for the whole book.
