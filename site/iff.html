Conjunctions and Biconditionals

Two halves, proved one at a time.

A goal of the form P ∧ Q is two goals. A goal of the form P ↔ Q is (P → Q) ∧ (Q → P): also two goals, each an if–then. Split them up and prove each part with whatever technique suits it.

(→) Suppose P. … so Q. (←) Suppose Q. … so P. Thus P ↔ Q. ∎

Givens work the same way: P ∧ Q is two givens, and P ↔ Q gives you both directions.

Example

An integer n is even if and only if n² is even

Each direction has already appeared on its own page. Here they're joined, and each half uses a different technique.

The goal is P ↔ Q. Split it into two if–then goals.

(→) Direct proof: assume n is even, write n = 2k, and compute.

(←) A direct start (“suppose n² = 2k”) goes nowhere, so prove the contrapositive: if n is odd, n² is odd.

Both directions are done, so the biconditional holds.

Goal (→)

  • n even ↔ n² even
  • n even → n² even
  • n even → n² even

Goal (←)

  • n² even → n even
  • n odd → n² odd
  • n odd → n² odd
Let n be an integer. (→) Suppose n is even, so n = 2k for some integer k. Then n² = 2(2k²), which is even. (←) We prove the contrapositive. Suppose n is odd, so n = 2k + 1. Then n² = 2(2k² + 2k) + 1, which is odd. Therefore n is even if and only if n² is even. ∎
Where you'll see it

Splitting is everywhere

A = B

Set equality

Prove A ⊆ B and B ⊆ A. Equivalently, prove x ∈ A ↔ x ∈ B for arbitrary x. See a full example.

x ∈ A ∩ B

Intersections

Unpacks to x ∈ A ∧ x ∈ B: prove both. As a given, it hands you both facts.

bijection

Two-part definitions

A bijection is one-to-one and onto. Prove each property separately.

P ↔ Q ↔ R

Chains of equivalences

To show three statements are all equivalent, a cycle P → Q → R → P is enough: three proofs instead of six.

Common slip

Proving only one direction of an “iff”, then stopping. Label the halves (→) and (←) as you write them so it's obvious to you and the reader that both are there.
