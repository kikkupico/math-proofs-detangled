How to Read a Proof

Recover the moves the author left out.

Proofs in books and papers are written for readers who already know the standard moves, so the routine ones are left out. Reading a proof means putting them back: at every line, knowing what the givens and goal are, and which move produced the line.

Theorem

If n² is even, then n is even.

Proof. If n is odd, n² is odd.

A complete, correct proof, as you might see it in print. Below, every move it skips is put back.

Unpack it

Four moves hiding in one line

Step through. Each step names a move the author expected you to supply, and the board shows what it does to the givens and goal.

Spot the form. The theorem is “if n² even, then n even”, but the proof starts from “n odd”, the negation of the conclusion. So it's proving the contrapositive: n odd → n² odd.

Unpack the definition. “n is odd” hides an ∃: n = 2k + 1 for some integer k. The author didn't write it.

Do the algebra. “n² is odd” needs a calculation the author thought was obvious: n² = 2(2k² + 2k) + 1.

Close the loop. Odd means not even, so we've shown: not (n even) → not (n² even). That's the contrapositive, which is equivalent to the theorem.

Givens

  • n is odd
  • n = 2k + 1

Goal

  • n² is odd
  • n² = 2(…) + 1
  • n² is odd
We prove the contrapositive. Suppose n is odd. Then n = 2k + 1 for some integer k. So n² = 4k² + 4k + 1 = 2(2k² + 2k) + 1, which is odd. Hence if n² is even, n is even. ∎
Follow the hypotheses

Where is each one used?

Every hypothesis in a theorem should be used somewhere in its proof. Tap one to light up the lines that depend on it.

Then drop it and see a counterexample: the theorem really does need it. If a proof never uses a hypothesis, either the proof has a gap or the theorem is true without it.

Theorem

For integers a, b, c: if H1: a | b and H2: a | c, then a | (b + c).

Suppose a | b and a | c. Then b = ja for some integer j, and c = ka for some integer k. So b + c = ja + ka = (j + k)a. Since j + k is an integer, a | (b + c). ∎

Tap a hypothesis.

A routine

Three passes through any proof

Before

Plan it yourself

Read only the theorem. Write its logical form. Which technique would you try? Now the proof is answering a question you already asked.

During

Justify every line

For each sentence, name what it follows from: a hypothesis, an earlier line, a definition, or a known theorem. Keep a givens-and-goal board as you go.

After

Test and retell

Run the proof on a specific example. Drop a hypothesis and find what breaks. Then summarise the proof as its list of moves, without looking.
