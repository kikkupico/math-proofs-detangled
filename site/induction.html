Proof by Induction

Infinitely many cases in two steps.

To prove ∀n ∈ ℕ P(n), prove two things. Base case: P(0). Induction step: for an arbitrary n, if P(n) then P(n + 1). Like dominoes: the first one falls, and each one knocks over the next.

Base case: … show P(0) … Induction step: let n ∈ ℕ be arbitrary, and suppose P(n). (inductive hypothesis) … show P(n + 1) … By induction, ∀n P(n). ∎
Try it

Why you need both steps

Push the first domino. Then break the base case, or break the step at one place, and see what's left of the proof.

Example

1 + 2 + ⋯ + n = n(n + 1)/2

Let P(n) be the statement “0 + 1 + 2 + ⋯ + n = n(n + 1)/2”. The key moment is step 3: the inductive hypothesis gets used.

Base case: check P(0). The sum is just 0, and 0(0 + 1)/2 = 0.

Induction step: let n be arbitrary and assume P(n). The goal is P(n + 1).

The sum up to n + 1 contains the sum up to n. Replace it using the inductive hypothesis.

Simplify, and the result is exactly the formula with n + 1 in place of n.

Both parts done, so P(n) holds for every natural number n.

Givens

  • 0 + ⋯ + n = n(n + 1)/2

Goal

  • P(0)
  • 0 + ⋯ + (n + 1) = (n + 1)(n + 2)/2
  • P(n + 1)
Base case: when n = 0, both sides equal 0. Induction step: let n ∈ ℕ and suppose 0 + 1 + ⋯ + n = n(n + 1)/2. Then 0 + 1 + ⋯ + n + (n + 1) = n(n + 1)/2 + (n + 1) = (n + 1)(n + 2)/2. By induction, the formula holds for all n ∈ ℕ. ∎
Variations

Other shapes of induction

Different start

Base case n = k

To prove P(n) for all n ≥ 5, check P(5) and prove the step for n ≥ 5. For example, 2ⁿ > n² for all n ≥ 5.

Strong induction

Lean on every smaller case

Assume P(k) for all k < n, then prove P(n). Used to show every integer ≥ 2 is a product of primes: if n = ab, both a and b are smaller, so they already factor.

Well-ordering

There's always a smallest one

Every nonempty set of natural numbers has a smallest element. Equivalent to induction, and often used inside proofs by contradiction: take the smallest counterexample.

Common slip

Proving the step by assuming P(n + 1) and working backwards, or never using the inductive hypothesis at all. If the hypothesis isn't used, you probably didn't need induction, or you've made a mistake.
