A Limit, by ε–δ

Every challenge ε gets an answer δ.

Theorem

limx→3 (2x + 1) = 7.

Tools

QuantifiersConditionals

Techniques

Arbitrary objectsWitnessesDirect proof
Definition

limx→a f(x) = L means

∀ε > 0 ∃δ > 0 ∀x (0 < |x − a| < δ → |f(x) − L| < ε)

Read it as a game. A challenger names any tolerance ε. You answer with a δ. You win if every x within δ of a has f(x) within ε of L. A proof is a strategy that wins for every ε.

Play the game

Answer every ε with a δ

Choose a function and a challenge ε. Then type your answer δ as a formula in ε (write it as e). The tester samples many x within δ of a and reports the worst one.

A formula that wins for one ε may lose for another. Drag the ε slider to check yours holds up.

Try e/2 for 2x + 1. For x², try e/6, then min(1, e/7), and push ε up to see the difference.

Scratch work

Work backwards from what you need

The proof starts “let δ = ε/2”, which looks like magic. It comes from scratch work done backwards, from the goal to the choice.

The scratch work stays out of the finished proof. The proof only has to show that the chosen δ works.

We need |(2x + 1) − 7| < ε. Simplify the left side.

It's twice the distance from x to 3. That's the quantity δ controls.

So we need |x − 3| < ε/2.

Choosing δ = ε/2 guarantees exactly that. For x², the same idea needs one extra trick: first keep x within 1 of 3, so |x + 3| < 7, giving δ = min(1, ε/7).

|(2x + 1) − 7| = |2x − 6| = 2|x − 3| 2|x − 3| < ε ⇔ |x − 3| < ε/2 so take δ = ε/2

Try it in LeanOpen in the Lean playground ↗

Lean is a proof assistant: it accepts a proof only if every step checks. This is the same proof, move for move, using the Mathlib library. The playground runs it in your browser tab; hover over any line to see the givens and goal at that point. For a whole course in this style, see Velleman's free book How To Prove It with Lean.

Show the Lean code
import Mathlib

/-! lim_{x → 3} (2x + 1) = 7, written out as ε–δ. -/

example : ∀ ε > 0, ∃ δ > 0, ∀ x : ℝ,
    0 < |x - 3| ∧ |x - 3| < δ → |(2 * x + 1) - 7| < ε := by
  intro ε hε                         -- Let ε > 0 be arbitrary.
  refine ⟨ε / 2, half_pos hε, ?_⟩    -- Let δ = ε/2, which is positive.
  rintro x ⟨-, hx⟩                   -- Let x be within δ of 3.
  have h : (2 * x + 1) - 7 = 2 * (x - 3) := by ring
  rw [h, abs_mul, abs_two]           -- |(2x + 1) − 7| = 2|x − 3|
  linarith                           -- < 2δ = ε
