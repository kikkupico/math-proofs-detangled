Proof by Cases

Split the world. Cover every piece.

Sometimes one argument can't handle every object at once, but two can. If you know P ∨ Q, prove the goal assuming P, then prove it again assuming Q. Either way the goal holds. The only rule: the cases must cover everything.

We know P ∨ Q. Case 1: P. … so the goal. Case 2: Q. … so the goal. In either case, the goal holds. ∎
Example 1

For every integer n, n² + n is even

Every integer is even or odd: that's the P ∨ Q to split on. Hover the number line: each integer falls into exactly one case, and each case gives its own reason that n² + n is even.

Let n be an integer. Case 1: n is even, say n = 2k. Then n² + n = 4k² + 2k = 2(2k² + k), which is even.

Case 2: n is odd, say n = 2k + 1. Then n² + n = 4k² + 6k + 2 = 2(2k² + 3k + 1), which is even.

In both cases n² + n is even.

Pick an integer

The definition of |x| itself comes in two cases, so split the same way.

Case 1: x ≥ 0. Then |x| = x, and x ≥ x.

Case 2: x < 0. Then |x| = −x, which is positive, so it's bigger than the negative number x.

Every real number is ≥ 0 or < 0, so the cases are exhaustive.

Let x be a real number. Case 1: x ≥ 0. Then |x| = x ≥ x. Case 2: x < 0. Then |x| = −x > 0 > x. In either case |x| ≥ x. ∎
Example 2

For every real x, |x| ≥ x

When a definition is given in pieces, like absolute value, maximum, or a function defined “by cases”, the proof usually follows the same pieces.

Cases also work for proving an “or” goal. To prove P ∨ Q, you can instead assume ¬P and prove Q: if P is true you're done, and if not, you've shown Q.

Common slip

Cases that leave a gap. “Case 1: x > 0. Case 2: x < 0” forgets x = 0. Before writing the cases, say why they cover everything: “every integer is even or odd”, “every real is ≥ 0 or < 0”.
