Why we need a mathematical language

Because English is slippery.

Everyday language runs on context and good will. A proof can't. If a sentence can be read two ways, an argument can be right under one reading and wrong under the other, and nobody notices. Mathematical language exists to make that impossible.

Find the second meaning

“All that glitters is not gold.”

∀x (G(x) → ¬Au(x))
Nothing that glitters is gold.
¬∀x (G(x) → Au(x))
Not everything that glitters is gold. (What the proverb means.)
Problem 1

One sentence, two claims

Each of these sentences has two reasonable readings, and they say different things. Pick a sentence, then switch between readings.

In symbols, the two readings look different. That's the point: the symbols force you to decide which one you mean.

Problem 2

Arguments that only look right

Either the butler or the maid did it. Either the maid or the cook did it. So either the butler or the cook did it.

Sounds fine? An argument is valid if the conclusion can't be false while the premises are all true. Set the suspects and try to find a situation where both premises are true but the conclusion is false.

The fix

Validity is about shape, not story

Replace each sentence with a letter and the butler argument becomes P ∨ Q, Q ∨ R, so P ∨ R. Any argument with this shape is invalid, whatever it's about. Here are two shapes, each told three ways.

Shapeinvalid
P ∨ Q, Q ∨ R ∴ P ∨ R
  • Butler or maid; maid or cook; so butler or cook.
  • It's Saturday or I'm tired; I'm tired or it's late; so it's Saturday or it's late.
  • x > 0 or x is even; x is even or x < −5; so x > 0 or x < −5. (Try x = −2.)
Shapevalid
P ∨ Q, ¬Q ∴ P
  • Butler or maid; not the maid; so the butler.
  • The key is in my coat or my bag; it's not in my bag; so it's in my coat.
  • n is even or n is odd; n is not odd; so n is even.
What the language buys you

Precision you can work with

¬ ∧ ∨

One meaning per sentence

“Or” always means at least one, possibly both. “If” always means exactly the same thing. No guessing what the author intended.
