Composite n Gives Composite 2ⁿ − 1

A proof that builds the factors.

Theorem

For every integer n > 1, if n is not prime, then 2n − 1 is not prime.

Where this came from

In Why we need proofs, “if n is prime then 2ⁿ − 1 is prime” broke at n = 11. The reverse direction survived every check. Checks aren't proofs; this is.

The key identity

(2b − 1)(1 + 2b + 22b + ⋯ + 2(a−1)b) = 2ab − 1

The proof, line by line

Turn a negative into a recipe

∀ and → goals

Set up

Let n > 1 be arbitrary and assume n is not prime. Both moves are routine.

Rewrite the negative

“Not prime” as something positive

“Not prime” is a negative, and negatives are hard to use. But for n > 1 it means there exist a, b with 1 < a, b < n and n = ab. That's an ∃ given: name them.

∃ goal

The goal is negative too

“2ⁿ − 1 is not prime” also means there exist factors x, y, each bigger than 1 and smaller than 2ⁿ − 1. So we need witnesses. The scratch work: factor 2ab − 1 like za − 1 with z = 2b.

Check the witnesses

Multiply out

Multiplying x by y, every term appears once with + and once with −, except the very top and bottom. Everything else cancels, leaving 2ab − 1 = 2n − 1.

Check the sizes

Both factors are proper

Since 1 < b < n, we get 1 < 2b − 1 < 2n − 1. So x is a genuine factor, neither 1 nor the whole number, and 2ⁿ − 1 isn't prime.

Proof
Let n > 1 be an integer, and suppose n is not prime. Then there are integers a, b with 1 < a < n, 1 < b < n and n = ab. Let x = 2b − 1 and y = 1 + 2b + 22b + ⋯ + 2(a−1)b. Then xy = (2b + 22b + ⋯ + 2ab) − (1 + 2b + ⋯ + 2(a−1)b) = 2ab − 1 = 2n − 1. Since 1 < b < n, we have 1 < x < 2n − 1. So 2n − 1 has a factor other than 1 and itself, and is not prime. ∎

Try it in LeanOpen in the Lean playground ↗

Lean is a proof assistant: it accepts a proof only if every step checks. This is the same proof, move for move, using the Mathlib library. The playground runs it in your browser tab; hover over any line to see the givens and goal at that point. For a whole course in this style, see Velleman's free book How To Prove It with Lean.

Show the Lean code
import Mathlib

/-! If n = a·b with a, b > 1 (so n is not prime), then 2ⁿ − 1 is not prime.
The "not prime" given is already unpacked into a and b here. -/

example (a b : ℕ) (ha : 1 < a) (hb : 1 < b) : ¬ Nat.Prime (2 ^ (a * b) - 1) := by
  -- The witness x = 2ᵇ − 1 divides 2^(ab) − 1 = (2ᵇ)ᵃ − 1ᵃ.
  have hx : 2 ^ b - 1 ∣ 2 ^ (a * b) - 1 := by
    have h := nat_sub_dvd_pow_sub_pow (2 ^ b) 1 a
    rw [one_pow, ← pow_mul, mul_comm b a] at h
    exact h
  -- Sizes: 4 ≤ 2ᵇ, and 2ᵇ < 2^(ab) because b < ab.
  have h4 : 4 ≤ 2 ^ b := by
    calc 4 = 2 ^ 2 := by norm_num
      _ ≤ 2 ^ b := Nat.pow_le_pow_right (by norm_num) (by omega)
  have hlt : 2 ^ b < 2 ^ (a * b) :=
    Nat.pow_lt_pow_right (by norm_num) (by nlinarith)
  -- So 1 < x < 2ⁿ − 1: a factor other than 1 and itself.
  exact Nat.not_prime_of_dvd_of_lt hx (by omega) (by omega)
The factor machine

The proof is a recipe. Run it.

Pick any composite n and a way to split it as a · b. The proof's formulas produce two factors of 2ⁿ − 1 immediately, with no searching. That's the advantage of a constructive proof: it doesn't just say factors exist, it builds them.
