A ∖ (B ∪ C) = (A ∖ B) ∩ (A ∖ C)

De Morgan's law, wearing set clothes.

Theorem

For all sets A, B and C,  A ∖ (B ∪ C) = (A ∖ B) ∩ (A ∖ C).

Shade a set

The proof, line by line

Translate, simplify, translate back

Two sets are equal when they have the same elements. So take an arbitrary x and show “x is in the left side” ↔ “x is in the right side”, through a chain of equivalences.

∀ goal

An arbitrary element

Set equality is ∀x (x ∈ left ↔ x ∈ right). Let x be arbitrary and start from the left.

Unpack ∖ and ∪

Into logic

∖ is “and not”, and ∪ is “or”. Now it's a statement of pure logic about three facts: x ∈ A, x ∈ B, x ∈ C.

De Morgan

Push the negation in

¬(P ∨ Q) ≡ ¬P ∧ ¬Q. The “not in B or C” becomes “not in B and not in C”.

Idempotence + regrouping

Use x ∈ A twice

Since R ≡ R ∧ R, we may write x ∈ A twice and regroup into two pairs, one for each set on the right.

Repack

Back into sets

Each pair is a set difference, and the ∧ between them is ∩. Every step was an equivalence, so both directions hold at once.

Proof
Let x be arbitrary. Then x ∈ A ∖ (B ∪ C) ↔ x ∈ A ∧ ¬(x ∈ B ∨ x ∈ C) ↔ x ∈ A ∧ x ∉ B ∧ x ∉ C ↔ (x ∈ A ∧ x ∉ B) ∧ (x ∈ A ∧ x ∉ C) ↔ x ∈ A ∖ B ∧ x ∈ A ∖ C ↔ x ∈ (A ∖ B) ∩ (A ∖ C). Since x was arbitrary, the two sets are equal. ∎
The pattern

Every set identity is a logic identity

Strip away the set notation and this theorem is De Morgan's law: P ∧ ¬(Q ∨ R) ≡ (P ∧ ¬Q) ∧ (P ∧ ¬R). Check it in the truth table.

That gives a reliable method for any identity built from ∩, ∪ and ∖: translate to logic, simplify with known laws, translate back. And if you suspect an identity is false, the truth table's mismatched row tells you exactly which region of the Venn diagram gives a counterexample.

P: x ∈ A, Q: x ∈ B, R: x ∈ C
