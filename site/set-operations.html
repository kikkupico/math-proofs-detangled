Set Operations

∩, ∪ and ∖ are ∧, ∨ and “and not”.

Every set operation is defined by a connective. Once you see that, the laws of logic from the Truth Tables page turn into laws about sets for free, and every set identity can be proved by translating it back into logic.

Operationx is in it when…
A ∩ Bx ∈ A ∧ x ∈ B
A ∪ Bx ∈ A ∨ x ∈ B
A ∖ Bx ∈ A ∧ ¬(x ∈ B)
A ⊆ B∀x (x ∈ A → x ∈ B)

Subsets and disjoint sets

Comparing sets

A ⊆ B means every element of A is also in B. In logic: ∀x(x ∈ A → x ∈ B). To prove it, you take an arbitrary element of A and show it's in B.

A and B are disjoint when they have no elements in common: A ∩ B = ∅.

Two sets are equal exactly when each is a subset of the other. Most set proofs check both directions.

A first theorem

(A ∪ B) ∖ B ⊆ A

Translate everything into logic and the proof writes itself. Step through it. You'll meet every move again in Part 3.

The goal is a subset statement, so take an arbitrary element of the left-hand set.

Unpack the definitions of ∖ and ∪.

We know x ∈ A or x ∈ B, and also x ∉ B. So the second option is ruled out.

That leaves x ∈ A, which is what we wanted.

Suppose x ∈ (A ∪ B) ∖ B. Then x ∈ A ∪ B and x ∉ B. So x ∈ A or x ∈ B; and x ∉ B. Since x ∉ B, it must be that x ∈ A. So every element of (A ∪ B) ∖ B is in A. ∎
