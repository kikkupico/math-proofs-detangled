Variables and Sets

Sets are statements you can hold.

“x is prime” is neither true nor false until you say what x is. Statements with variables lead straight to sets: the set of all x that make the statement true. Sets turn out to be the natural home for almost everything in mathematics.

{ x ∈ ℕ | x is prime }

“the set of all natural numbers x such that x is prime”

{2, 3, 5, 7, 11, 13, …}
Truth sets

A statement picks out a set

A statement P(x) with a variable is true for some values and false for others. The values that make it true form its truth set, written {x | P(x)}.

Choose a statement and watch which numbers from 1 to 30 land in its truth set. The key fact is the bridge between logic and sets: a ∈ {x | P(x)} means exactly P(a).

Which variables are free?
{x | x > y}

Here x is just a placeholder. Replace it with w and you get {w | w > y}, the same set. So x is bound.

But y matters: you can't say what the set is until you know y. So y is free.

So “3 ∈ {x | x > y}” is a statement about y alone. It means 3 > y: true if y = 1, false if y = 5.

Free and bound

Some letters matter, some don't

A free variable needs a value before the statement can be true or false. A bound variable is a dummy: it's used internally and can be renamed without changing the meaning.

This distinction matters in proofs, because you're never allowed to use a letter that already means something. When a definition uses x as a bound variable, you can rename it to avoid a clash.

Basics

Facts about sets

∈

Membership

a ∈ A: a is an element of A. a ∉ A: it isn't. That's the only thing a set “knows”.

{1, 2} = {2, 1, 1}

Order and repeats don't count

Two sets are equal when they have exactly the same elements. Listing order and repetition make no difference.

∅

The empty set

The set with no elements. For example {x ∈ ℝ | x² < 0} = ∅. There is only one empty set.

ℕ ℤ ℚ ℝ

Standard sets

Natural numbers {0, 1, 2, …}, integers, rationals (fractions), and reals. ℤ⁺ is the positive integers.
