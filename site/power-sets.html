Power Sets

Every subset, collected into one set.

Sets can contain other sets. The most important example is the power set 𝒫(A): the set whose elements are all the subsets of A. It looks innocent, and it is the key to showing that some infinities are bigger than others.

𝒫(A) = { X | X ⊆ A }
𝒫({1, 2}) = { ∅, {1}, {2}, {1, 2} }

So X ∈ 𝒫(A) means exactly X ⊆ A.

Try it

Each new element doubles the count

Build a subset by going through the elements one by one and deciding: in or out. With n elements that's n independent yes/no choices, so there are 2 × 2 × ⋯ × 2 = 2ⁿ subsets.

Slide n up. Each row of the table is one subset; the dots show which elements were chosen. Adding an element copies every old subset twice: once without it, once with it.

𝒫({1, …, n})

Careful

∈ is not ⊆

With sets of sets, it's easy to mix up “is an element of” and “is a subset of”. Take A = {1, 2, 3}.

1 ∈ Atrue

1 is one of the elements of A.

{1} ∈ 𝒫(A)true

{1} ⊆ A, so it's an element of the power set.

1 ∈ 𝒫(A)false

Elements of 𝒫(A) are sets. The number 1 isn't one of them.

∅ ∈ 𝒫(A), A ∈ 𝒫(A)true

The empty set and A itself are always subsets of A.
