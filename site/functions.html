Functions

One input, exactly one output.

A function f : A → B assigns to each element of A exactly one element of B. Two properties, one-to-one and onto, decide whether it can be undone, and whether A and B have the same size.

Function
∀a ∈ A ∃!b ∈ B (f(a) = b)
One-to-one (injective)
∀a1 ∀a2 (f(a1) = f(a2) → a1 = a2)
Onto (surjective)
∀b ∈ B ∃a ∈ A (f(a) = b)

The facts you'll use

How the properties behave

Equal functions

Two functions f, g : A → B are equal when ∀a ∈ A (f(a) = g(a)). Same outputs everywhere; the formula doesn't matter.

Composition

(g ∘ f)(a) = g(f(a)). If f and g are both one-to-one, so is g ∘ f; the same for onto.

Inverses

f has an inverse f⁻¹ : B → A exactly when it's one-to-one and onto: a bijection.

Same size

Sets A and B have the same size when there's a bijection between them. For infinite sets this is the only sensible definition, and it leads to Cantor's theorem.

Not one-to-one, in symbols

Negating a definition tells you what to look for

Negate the definition of one-to-one with the quantifier laws and you get ∃a1 ∃a2 (f(a1) = f(a2) ∧ a1 ≠ a2): two different inputs with the same output.

For f(x) = x² on ℝ, take 2 and −2. For “not onto”, find one b that's never hit: −1 isn't a square.
