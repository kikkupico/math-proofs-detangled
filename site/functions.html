Chapter 5 · pp. 226–259

Functions

One input. Exactly one output.

In this book a function is a relation with one extra requirement: every input gets exactly one output. Make that precise and one-to-one, onto and inverses follow from it.

Draw a functionTry the research project
∀a ∈ A ∃!b ∈ B ((a, b) ∈ f)

Key ideas

Definition

A function from A to B is a relation with exactly one output per input.

We write f(a) for the unique b with (a, b) ∈ f.

f : A → B
Equality

Same outputs everywhere means the same function.

Theorem 5.1.4: if f(a) = g(a) for every a ∈ A, then f = g. How the rule is written doesn't matter.

f = g
One-to-one

Different inputs give different outputs.

Formally, f(a₁) = f(a₂) implies a₁ = a₂. Nothing in B gets hit twice.

1–1
Onto

Every element of B gets hit.

For every b ∈ B there is some a ∈ A with f(a) = b. The range is all of B.

↠
Inverses

One-to-one and onto ⇔ an inverse exists.

Flipping the pairs of f gives a function exactly when f is a bijection.

f ⁻¹
Composition

g ∘ f: do f, then g.

It's relation composition from Chapter 4, and it keeps one-to-one and onto.

g ∘ f
Try it · §5.1–5.3

Draw a function

Click an element of A, then an element of B, to send it there. Clicking the same target again removes the arrow. The lab checks whether what you've drawn is a function and, if so, whether it's one-to-one and onto. Make a bijection and you can flip it.

The theorems that hold it together

Short statements whose proofs are good practice with Chapter 3's strategies. Try each one before you read the book's version.

Theorem 5.1.5

Composition gives a function.

If f : A → B and g : B → C, then g ∘ f : A → C and (g ∘ f)(a) = g(f(a)).

Theorem 5.2.5

Composition keeps both properties.

If f and g are both one-to-one, so is g ∘ f. If both are onto, so is g ∘ f.

Theorems 5.3.1 & 5.3.4

A bijection's inverse is a bijection.

If f is one-to-one and onto, then f⁻¹ : B → A is a function (5.3.1). It is also one-to-one and onto (5.3.4).

Theorem 5.3.2

Undo, then redo.

If f⁻¹ is a function, then f⁻¹ ∘ f = iA and f ∘ f⁻¹ = iB.

Theorem 5.3.5

Inverses are unique.

If g ∘ f = iA and f ∘ g = iB, then g = f⁻¹. This gives a practical way to show f is a bijection: find a g that undoes it.

§5.4 · A research project

Now you make the conjectures

The chapter ends unusually. Instead of stating theorems, it defines two new operations and asks you to find out which identities hold. This is what mathematical research is like.

The image f(X) is the set of outputs of the elements of X. The inverse image f⁻¹(Y) is the set of inputs whose output lands in Y. The inverse image makes sense even when f has no inverse.

Starter questions
f(W ∩ X) ⊆ f(W) ∩ f(X) ?

This is the book's worked example, Theorem 5.4.2. It always holds, and it becomes an equality when f is one-to-one. To see equality fail, try f(x) = x² with W = {−1}, X = {1}.

f(W ∪ X) = f(W) ∪ f(X) ?

The first question the book asks you. Decide whether it always holds, then prove it or find a counterexample.

f⁻¹(Y ∩ Z) = f⁻¹(Y) ∩ f⁻¹(Z) ?

Hint: inverse images behave better than images. Try a few small examples first.

For each identity that fails in general, look for an extra condition, like one-to-one or onto, that makes it hold.
