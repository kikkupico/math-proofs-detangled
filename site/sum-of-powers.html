Induction, start to finish.

Theorem

For every natural number n,  2⁰ + 2¹ + 2² + ⋯ + 2n = 2n+1 − 1.

The proof, line by line

A base case and one step

Name the statement

What is P(n)?

Write down exactly what you're proving for each n. Being explicit here prevents most induction mistakes.

Base case

Check n = 0

The left side is just 2⁰ = 1. The right side is 2¹ − 1 = 1. They match.

Induction step · ∀ and →

Assume P(n), aim for P(n + 1)

The step is ∀n (P(n) → P(n + 1)). So: let n be arbitrary and assume P(n), the inductive hypothesis.

Use the hypothesis

Spot the old sum inside the new one

The sum up to 2n+1 is the sum up to 2n, plus one more term. Replace the old sum with 2n+1 − 1. This is the only place the hypothesis is used, and it's essential.

Simplify

Two halves make a whole

2n+1 + 2n+1 = 2n+2. In the picture: the gap of size 2n+1 is filled by the next power, leaving the same single unit gap.

Proof
For n ∈ ℕ, let P(n) be the statement 2⁰ + ⋯ + 2n = 2n+1 − 1. We use induction. Base case: 2⁰ = 1 = 2¹ − 1, so P(0) holds. Induction step: let n ∈ ℕ and suppose 2⁰ + ⋯ + 2n = 2n+1 − 1. Then 2⁰ + ⋯ + 2n + 2n+1 = (2n+1 − 1) + 2n+1 = 2 · 2n+1 − 1 = 2n+2 − 1, which is P(n + 1). By induction, P(n) holds for all n ∈ ℕ. ∎
Why it matters

Binary in disguise

In binary, 2⁰ + 2¹ + ⋯ + 2n is a string of n + 1 ones: 1111₂ = 15 = 16 − 1. Adding 1 makes everything carry into a single 1 followed by zeros.

The same pattern, 1 + r + ⋯ + rn = (rn+1 − 1)/(r − 1), holds for any r ≠ 1, and the induction proof is almost identical. It's also the identity hiding inside the Mersenne proof.

Your turnSomeone proves only the induction step, never the base case, for the false claim “2⁰ + ⋯ + 2n = 2n+1”. Does the step go through?
