Craft

Knowing the moves is half of it.

The first four parts teach what proofs are made of. This part is about the work around them: reading a proof someone else wrote, writing one a reader can follow, catching the mistakes everyone makes, and finding a way in when you have no idea where to start.

Draft. n odd ⇒ n=2k+1 ⇒ n²=4k²+4k+1 odd ∎

Proof. Let n be an odd integer. Then n = 2k + 1 for some integer k, so n² = 4k² + 4k + 1 = 2(2k² + 2k) + 1. Since 2k² + 2k is an integer, n² is odd.

Same mathematics. Only the second one is a proof a reader can check.
