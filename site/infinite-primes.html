There Are Infinitely Many Primes

Euclid's argument, move by move.

Theorem (Euclid, c. 300 BC)

There are infinitely many prime numbers.

One fact we'll use

Every integer greater than 1 is either prime or a product of primes. So every integer > 1 has at least one prime factor. (That fact is itself proved by strong induction.)

The shape of the goal

“Infinitely many” means “not finitely many”. A negative goal: a signal to try contradiction.

The proof, line by line

Assume a complete list. Break it.

Negative goal → contradiction

Suppose there are only finitely many

Assume the opposite of the goal: the primes can be listed completely as p1, p2, …, pn. Now we hunt for a contradiction.

The creative step

Build a number from the list

Multiply all of them and add 1. This is the one idea in the proof that isn't a standard move. Everything else follows from the shapes of the statements.

Cases → ∃ given

It has a prime factor

m > 1, so either m is prime (then it's its own prime factor) or it's a product of primes. In either case, some prime q divides m. Name it.

Use the assumption

q must be on the list

The list is assumed complete, so q is one of the pi. But dividing m by any pi leaves remainder 1, so pi doesn't divide m.

Contradiction

Two facts that can't both hold

q divides m, and q doesn't divide m. The assumption must be false, so there are infinitely many primes.

Proof
Suppose, for contradiction, that there are only finitely many primes, and list them all: p1, …, pn. Let m = p1p2⋯pn + 1. Then m > 1, so m is prime or a product of primes. Either way, some prime q divides m. Since the list contains every prime, q = pi for some i. But dividing m by pi leaves remainder 1, so pi does not divide m. This contradicts q | m. So there are infinitely many primes. ∎

Show the Lean code
import Mathlib

/-! There are infinitely many primes, stated as: no N is at least every prime.
Instead of multiplying a finite list of primes we use N!, which every
prime p ≤ N divides. The idea is Euclid's. -/

example : ¬ ∃ N, ∀ p, Nat.Prime p → p ≤ N := by
  rintro ⟨N, hN⟩                       -- Suppose every prime is ≤ N.
  have hm : N.factorial + 1 ≠ 1 := by  -- m = N! + 1 is bigger than 1,
    have := Nat.factorial_pos N
    omega
  -- so it has a smallest prime factor q.
  have hq : Nat.Prime (Nat.minFac (N.factorial + 1)) := Nat.minFac_prime hm
  -- q is on the "list" (q ≤ N), so q divides N!.
  have h1 : Nat.minFac (N.factorial + 1) ∣ N.factorial :=
    Nat.dvd_factorial hq.pos (hN _ hq)
  -- q also divides m = N! + 1.
  have h2 : Nat.minFac (N.factorial + 1) ∣ N.factorial + 1 := Nat.minFac_dvd _
  -- So q divides the difference, 1. Contradiction.
  have h3 : Nat.minFac (N.factorial + 1) ∣ 1 := (Nat.dvd_add_right h1).mp h2
  exact hq.not_dvd_one h3

A list that grows forever

Start with just {2}. Each press applies Euclid's construction: multiply the list, add 1, and add its smallest prime factor to the list. It's always new.

Note what the proof does not claim: m itself needn't be prime. Press a few times and you'll see a composite m show up.
