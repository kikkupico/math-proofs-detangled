No Set Is as Big as Its Power Set

The diagonal trick, made precise.

Cantor's theorem

For every set A, no function f : A → 𝒫(A) is onto.

Tools

FunctionsPower setsSet-builder

Techniques

Arbitrary objectsContradictionWitnesses
Why it's a big deal

Two sets have the same size when a bijection matches them up. For finite sets, 𝒫(A) has 2ⁿ elements, obviously more than n. Cantor's theorem says the same holds for infinite sets: 𝒫(ℕ) is a strictly bigger infinity than ℕ, and 𝒫(𝒫(ℕ)) is bigger still. There is no largest infinity.

The proof, line by line

Build the set that f misses

∀ goal

Take any function

The theorem is about every f, so let f : A → 𝒫(A) be arbitrary. Goal: f is not onto. Negating the definition of onto, that means finding a set in 𝒫(A) that f never hits: an ∃ goal.

The witness

The diagonal set

Each x ∈ A gets a set f(x), and x is either in its own set or not. Collect the elements that are not. That's D, and it's a subset of A, so D ∈ 𝒫(A).

Negative goal → contradiction

Suppose f does hit D

To show D is never hit, assume the opposite: D = f(a) for some a ∈ A. That's an ∃ given, so name it a.

Ask one question

Is a in D?

By the definition of D, a ∈ D exactly when a ∉ f(a). But f(a) is D. So a ∈ D ↔ a ∉ D, which can't be: either answer contradicts itself.

Conclude

f misses D

So no a has f(a) = D, and f is not onto. Since f was arbitrary, no function from A to 𝒫(A) is onto.

Proof
Let A be a set and f : A → 𝒫(A) any function. Let D = { x ∈ A | x ∉ f(x) }. Then D ⊆ A, so D ∈ 𝒫(A). Suppose, for contradiction, that D = f(a) for some a ∈ A. Then a ∈ D ↔ a ∉ f(a) ↔ a ∉ D, which is impossible. So D is not in the range of f, and f is not onto. ∎

import Mathlib

/-! Cantor's theorem: no function from A onto 𝒫(A).
Mathlib also has this as `Function.cantor_surjective`. -/

example {α : Type*} (f : α → Set α) : ¬ Function.Surjective f := by
  intro hf                              -- Suppose f is onto.
  -- The diagonal set D = {x | x ∉ f x} is hit by some a.
  obtain ⟨a, ha⟩ := hf {x | x ∉ f x}
  -- Is a in D?
  by_cases h : a ∈ f a
  · have h2 := h
    rw [ha] at h2                       -- a ∈ D, so a ∉ f a
    simp only [Set.mem_setOf_eq] at h2
    exact h2 h
  · apply h
    rw [ha]                             -- a ∉ f a, so a ∈ D = f a
    exact h
