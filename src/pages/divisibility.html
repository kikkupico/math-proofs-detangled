Theorem

For all integers a, b and c, if a | b and b | c, then a | c.

Tools

QuantifiersConditionals

Techniques

Arbitrary objectsDirect proofWitnesses
Definition

a | b  means  ∃k ∈ ℤ (b = ka)

“a divides b”: b is a whole multiple of a. So 3 | 12 because 12 = 4 · 3, but 5 ∤ 12.

In logical form

∀a ∀b ∀c ((a | b ∧ b | c) → a | c)

The proof, line by line

Read the shape, make the move

Scroll. Each step explains one move, and the line it writes lights up.

Move 1 · ∀ goal

Let them be arbitrary

The outermost symbol is ∀ (three times). So introduce arbitrary integers a, b, c, assuming nothing else about them.

Move 2 · → goal

Assume the hypothesis

What's left is an if–then. Assume a | b and b | c. The goal becomes a | c.

Move 3 · unpack + ∃ givens

Name what the givens promise

Unpacked, each given is an ∃: some integer works. Give each one a new name: d with b = da, and e with c = eb. Different letters, because they may be different numbers.

Move 4 · ∃ goal

Find the witness

The goal a | c unpacks to ∃k (c = ka). Substitute: c = eb = e(da) = (ed)a. So the witness is k = ed, an integer.

Close the blocks

Done

Each move opened a block; they close in reverse order. Written proofs often leave the closing lines unsaid, because readers expect them.

Proof
Let a, b and c be arbitrary integers. Suppose a | b and b | c. Since a | b, there is an integer d with b = da. Similarly there is an integer e with c = eb. Then c = eb = e(da) = (ed)a. Since ed is an integer, a | c. Since a, b, c were arbitrary, the theorem holds. ∎
See it with numbers

The witness, computed

Choose a, then the multipliers d and e. The proof's recipe gives c as a multiple of a straight away: the multiplier is always ed.

That's what a constructive ∃ proof gives you: not just “a multiplier exists” but the multiplier itself.
