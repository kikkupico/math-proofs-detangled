Theorem

For all sets A and B,  𝒫(A ∩ B) = 𝒫(A) ∩ 𝒫(B).

Tools

Power setsSet operations

Techniques

Two directionsArbitrary objectsDirect proof
Two layers of unpacking

X ∈ 𝒫(S)  ↔  X ⊆ S

X ⊆ S  ↔  ∀x (x ∈ X → x ∈ S)

Elements of power sets are sets. So the proof has two kinds of arbitrary object: a set X, and then an element x of X.

The proof, line by line

Two subset proofs, each with a subset proof inside

Equality = two inclusions

Plan

To prove two sets equal, prove each is a subset of the other. Label the halves (⊆) and (⊇).

(⊆) · ∀ goal

An arbitrary element of the left side

Elements of 𝒫(A ∩ B) are sets, so call it X. Unpack: X ⊆ A ∩ B. The goal unpacks to X ⊆ A and X ⊆ B.

(⊆) · ∀ goal again

A subset proof inside

X ⊆ A is itself a ∀ goal. Take an arbitrary x ∈ X. Using the given X ⊆ A ∩ B, x ∈ A ∩ B, so x ∈ A. Same for B.

(⊇) · ∀ goal

Now the other way

Take X ∈ 𝒫(A) ∩ 𝒫(B). Unpack the ∩: two givens, X ⊆ A and X ⊆ B. Goal: X ⊆ A ∩ B.

(⊇) · use both givens

Element chase

Take an arbitrary x ∈ X. Each given puts it in A and in B, so it's in A ∩ B. Both inclusions done.

Proof
Let A and B be sets. We prove both inclusions. (⊆) Let X ∈ 𝒫(A ∩ B), so X ⊆ A ∩ B. Let x ∈ X. Then x ∈ A ∩ B, so x ∈ A and x ∈ B. Since x was arbitrary, X ⊆ A and X ⊆ B, so X ∈ 𝒫(A) ∩ 𝒫(B). (⊇) Let X ∈ 𝒫(A) ∩ 𝒫(B), so X ⊆ A and X ⊆ B. Let x ∈ X. Then x ∈ A and x ∈ B, so x ∈ A ∩ B. So X ⊆ A ∩ B, i.e. X ∈ 𝒫(A ∩ B). Both inclusions hold, so the sets are equal. ∎
Try it

Does the same work for ∪?

Choose A and B from {1, 2, 3}. For ∩ the two sides always match. Switch to ∪: is 𝒫(A ∪ B) = 𝒫(A) ∪ 𝒫(B)?

Usually not. With A = {1} and B = {2}, the set {1, 2} is a subset of A ∪ B but of neither A nor B. The proof above breaks exactly where (⊆) would need “x ∈ A ∪ B” to put all of X on one side.
