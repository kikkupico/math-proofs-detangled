Many proofs need the negation of a statement written in a positive form, one you can actually work with. Two laws do almost all the work: a negation flips each quantifier it passes through.

¬∀x P(x) ≡ ∃x ¬P(x)

“Not everything is P” = “something isn't P”

¬∃x P(x) ≡ ∀x ¬P(x)

“Nothing is P” = “everything isn't P”

Try it

The negation machine

Pick a statement and push the ¬ inward one step at a time. It flips each quantifier it passes. When it meets ∧ or ∨, De Morgan's laws take over. When it meets →, the conditional law ¬(P → Q) ≡ P ∧ ¬Q does.

The end result tells you exactly what you'd need to show to prove the original statement false.

More equivalences

Quantifiers meet connectives

Bounded quantifiers∀x ∈ A P(x) ≡ ∀x (x ∈ A → P(x))
∃x ∈ A P(x) ≡ ∃x (x ∈ A ∧ P(x))

The negation laws work the same way: ¬∀x ∈ A P(x) ≡ ∃x ∈ A ¬P(x).

Vacuous truth∀x ∈ ∅ P(x) is always true

“Every element of the empty set is purple” is true: there's nothing in ∅ that could be a counterexample. This is why ∅ ⊆ A for every A.

∀ distributes over ∧∀x (P(x) ∧ Q(x)) ≡ ∀x P(x) ∧ ∀x Q(x)

But not over ∨: every integer is even or odd, yet it's false that every integer is even or every integer is odd.

∃ distributes over ∨∃x (P(x) ∨ Q(x)) ≡ ∃x P(x) ∨ ∃x Q(x)

But not over ∧: some integer is even and some is odd, but no integer is both.

Exactly one

∃! is shorthand

∃!x P(x) means “there is exactly one x with P(x)”. It isn't a new kind of quantifier: it unpacks into ∃, ∀ and =.

Read the unpacked form as two claims: something has property P, and anything else with property P is that same thing. Part 3 shows how to prove it.

∃!x P(x)
∃x ( P(x) ∧ ∀y (P(y) → y = x) )

Example: ∃!x ∈ ℝ (2x + 1 = 7) is true: x = 3 works, and any y with 2y + 1 = 7 must equal 3. But ∃!x ∈ ℝ (x² = 4) is false: both 2 and −2 work.
