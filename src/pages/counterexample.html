Proving a “for all” takes a general argument. Disproving one takes a single object. By the quantifier laws, ¬∀x P(x) ≡ ∃x ¬P(x), so disproving a ∀ is just proving an ∃: find one witness where it fails.

Claim: ∀x P(x). We show it's false. Let x = [counterexample]. … check that P(x) fails … So ¬∀x P(x). ∎

For an if–then, a counterexample makes the hypothesis true and the conclusion false.

Notice what a counterexample to an if–then needs: the “if” part true and the “then” part false. A value that fails the “if” part tells you nothing.

Asymmetry

What it takes, at a glance

∀x P(x)

Prove: general argument. Disprove: one example.

No number of examples proves it. One example disproves it.

∃x P(x)

Prove: one example. Disprove: general argument.

To show nothing has property P, you must prove ∀x ¬P(x), which needs an arbitrary x.

Common slip

Offering a counterexample to a different statement. For “if n is prime then n is odd”, the number 9 is not a counterexample (it's odd; the conclusion holds). The number 2 is: prime, and not odd.
