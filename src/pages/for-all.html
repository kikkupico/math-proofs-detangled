You can't check infinitely many cases one by one. Instead, reason about a single object x about which you assume nothing except what the theorem says. Whatever you prove about that x, you've proved about every x.

Let x be arbitrary. … prove P(x), using only what's true of every x … Since x was arbitrary, ∀x P(x). ∎

To use a ∀ given instead: plug in any specific value you like.

Example 1

For every real x, x² + 1 ≥ 2x

Drag x around: the curve x² + 1 always sits on or above the line 2x. That's convincing, but it's still just examples.

The proof never picks a value. It works with a general x: since x² + 1 − 2x = (x − 1)² and squares are never negative, the gap is always ≥ 0. The gap you see in the picture is (x − 1)².

Let x be an arbitrary real number. Then x² + 1 − 2x = (x − 1)² ≥ 0, so x² + 1 ≥ 2x. Since x was arbitrary, this holds for all real x. ∎

Example 2

If A ⊆ B and B ⊆ C, then A ⊆ C

This one uses ∀ in both directions. The goal A ⊆ C unpacks to a ∀, so we introduce an arbitrary x. The givens are also ∀ statements, so we plug that same x into them.

Unpack the definitions. All three statements are “for all” statements.

The goal is ∀x(…). Let x be arbitrary. The goal becomes x ∈ A → x ∈ C, so also assume x ∈ A.

Use a ∀ given: it holds for every element, so in particular for our x. With x ∈ A, that gives x ∈ B.

Do it again with the second given: x ∈ B gives x ∈ C. Goal reached.

Givens

  • ∀y (y ∈ A → y ∈ B)
  • ∀y (y ∈ B → y ∈ C)
  • x ∈ A
  • x ∈ B
  • x ∈ C

Goal

  • ∀x (x ∈ A → x ∈ C)
  • x ∈ C
  • x ∈ C
Suppose A ⊆ B and B ⊆ C. Let x be an arbitrary element of A. Since A ⊆ B, x ∈ B. Since B ⊆ C, x ∈ C. Since x was arbitrary, A ⊆ C. ∎
Common slip

Sneaking in assumptions. If your proof of “for all integers n” says “take n = 4”, or quietly assumes n is positive, it only covers some cases. Another slip: reusing a letter that already means something. In Example 2 the givens use y as a bound variable, so we're free to call our element x.
