To prove that something exists, the cleanest way is to produce it. Name a specific object, called a witness, and check it has the property. Finding the witness is the creative part; it happens in scratch work, and the final proof just presents it.

Let x = [the witness]. … check that P(x) holds … Thus ∃x P(x). ∎

To use an ∃ given: give the promised object a new name, and work with it.

Example 1

There is a prime p such that p + 2 and p + 4 are also prime

Search for a witness. Try some values of p and see which work.

Once you've found one, the proof is a single line: Let p = 3. Then p, p + 2 = 5 and p + 4 = 7 are all prime. ∎ Nothing about the search appears in it.

Curious fact: 3 is the only witness. Among p, p + 2, p + 4 one is always divisible by 3.

Hunt for a witness

x is given. Pick y.

Example 2

For every x > 0, there is a y with 0 < y < x

A ∀ then an ∃. First let x be an arbitrary positive number. Now you need a witness, and it's allowed to depend on x: you chose it after seeing x.

Take y = x/2. Then 0 < x/2 < x. Slide x: the witness moves with it, and it always works.

Example 3

If a | b, then a | bc

Here a | b means “a divides b”: ∃k ∈ ℤ (b = ka). So the hypothesis is an ∃ given, and the goal is an ∃ goal. Both moves in one proof.

Unpack “divides” on both sides. Both are ∃ statements.

Use the ∃ given: it promises some integer works, so name it k. Use a letter not already in use.

Find the witness for the goal: bc = (ka)c = (kc)a. So j = kc works, and it's an integer.

Done. The proof is three sentences.

Givens

  • ∃k ∈ ℤ (b = ka)
  • b = ka, k ∈ ℤ

Goal

  • ∃j ∈ ℤ (bc = ja)
  • ∃j ∈ ℤ (bc = ja)
Suppose a | b. Then there is an integer k with b = ka. So bc = (kc)a, and kc is an integer. Therefore a | bc. ∎
Common slip

Letting the witness depend on something it can't. In “∃y ∀x”, y is chosen before x, so it can't mention x. And when using an ∃ given, never reuse a name: if k is already taken, call the new object m.
