P → Q is equivalent to ¬Q → ¬P. So instead of proving the original, you can assume ¬Q and prove ¬P. Same theorem, but sometimes a far better starting point.

We prove the contrapositive. Suppose ¬Q. … work … Therefore ¬P. Thus ¬Q → ¬P, so P → Q. ∎

Why it's allowed: the two have identical truth tables. Check it on the Conditionals page.

Example 1

If n² is even, then n is even

Try it directly: suppose n² = 2k. Now what? You'd need a square root of 2k, and that leads nowhere.

The contrapositive is: if n is odd, then n² is odd. Now the hypothesis hands you a formula for n, and the rest is algebra. Step through it.

Announce the strategy, then assume ¬Q: n is not even, i.e. odd.

Unpack “odd”.

Compute n² and put it into the form 2(integer) + 1.

We've proved ¬Q → ¬P, which is equivalent to P → Q.

Givens

  • n is odd
  • n = 2k + 1

Goal

  • n² is odd
  • n² is odd
We prove the contrapositive. Suppose n is odd. Then n = 2k + 1 for some integer k. So n² = 4k² + 4k + 1 = 2(2k² + 2k) + 1, which is odd. Thus if n is odd then n² is odd, and so if n² is even then n is even. ∎

The conclusion is an “or”. Its negation, by De Morgan, is an “and”: a < 8 and b < 8. That's a much better thing to assume.

For integers, a < 8 means a ≤ 7.

Add the two inequalities and we've shown ¬P.

We prove the contrapositive. Suppose a < 8 and b < 8. Since a and b are integers, a ≤ 7 and b ≤ 7. So a + b ≤ 14 < 15. ∎
Example 2

If a + b ≥ 15, then a ≥ 8 or b ≥ 8

Here a and b are integers. A direct proof would start from a single inequality about a sum and have to split it somehow.

The contrapositive turns the awkward “or” in the conclusion into a friendly “and” in the hypothesis. This is a common pattern: when the conclusion is an “or”, or a negative statement, try the contrapositive.

Common slip

Proving the converse by mistake. The converse of “if n² is even then n is even” is “if n is even then n² is even”. That's a true statement too, but proving it doesn't prove the original. The contrapositive negates and swaps.
