How the tools connect

It's all one idea, repeated

Almost every tool here is defined in terms of the ones before it. ∩ is defined with ∧. ⊆ is defined with ∀ and →. 𝒫(A) is defined with ⊆. A one-to-one function is defined with ∀, → and =.

That's good news. When you're stuck on a statement full of set notation, you can always unpack it, layer by layer, into plain logic. Part 3 calls this the first move of every proof.

Unpacking one statement
X ∈ 𝒫(A ∩ B)
X ⊆ A ∩ B · definition of 𝒫
∀x (x ∈ X → x ∈ A ∩ B) · definition of ⊆
∀x (x ∈ X → (x ∈ A ∧ x ∈ B)) · definition of ∩
